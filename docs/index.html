3. What the deterministic pass knows before any model is asked

What a deterministic pass sees (no model involved):
  - code, line 2: zero-width character U+200B
  - platform fact [invisible-text]: Some characters take no space on screen yet belong to the string. A byte order mark (U+FEFF) glues itself to the first CSV header or JSON key. A zero-width space (U+200B) makes two keys that look identical unequal. A non-breaking space (U+00A0) is not a separator for shells or YAML. Bidirectional controls (U+202E) reorder how code is displayed. When the repr of a value differs from what the editor shows, suspect one of these.
